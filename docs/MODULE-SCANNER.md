# Module serial scanner

Open **Module Serial Scanner** from the home page. Enter the site, operator, inverter, MPPT and string, then enable GPS and start the camera. Wait for a GPS position before scanning if coordinates are required. Point the camera at the module's serial-number barcode and check the saved value; other product barcodes may encode different information. A hardware barcode scanner or manual typing can also enter a serial.

The selected-string table shows the latest 200 records and a total count; uncheck the filter to see the latest records across the site. Excel export always contains all records for the entered site, grouped by inverter, MPPT, string and position. Serial numbers are written as text, preserving leading zeroes. Each row includes the operator name as entered, scan time in local and UTC forms, the recorded time zone, entry method and any recent GPS position, accuracy and capture time. GPS can be missing, imprecise, stale or denied; missing locations are explicitly marked unavailable.

Records are stored in IndexedDB on the device, not automatically synchronized between phones or with the website. Export the site workbook regularly and keep a secure copy. The application's general local-storage backup does not include this inventory. Clearing browser/app data or uninstalling the app can erase it. Site names are matched without case; serials are compared exactly within each site. Each accepted entry is stored immediately, and duplicate serials in that site are rejected. Users can remove an incorrect entry after a confirmation.

Camera scanning uses the bundled Apache-2.0 ZXing JavaScript library; Excel export uses bundled SheetJS 0.20.3 (Apache-2.0). The Android test APK requests camera and location only when needed and uses the Android document picker for inventory workbooks. A new application ID allows installation alongside the earlier test build, whose saved data is separate. Hosted test APKs have temporary signing keys; use a stable private signing key for reliable in-place production updates.
