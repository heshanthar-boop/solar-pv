# Ground Site Survey

Open **Ground Site Survey** from either home screen. Enter a site name and choose **Open site**. Optionally enter the survey operator. Select **Boundary**, walk to each corner and press **Add current GPS point**, or tap the map to mark an approximate point. A third point closes the polygon automatically. Undo removes the most recent point in the selected mode; clearing points asks for confirmation. Different site names are saved independently on the device.

The map offers OpenStreetMap street tiles and Esri World Imagery with their respective attributions. Viewing either requires an internet connection; providers receive requests for the visible map area. This app does not preload or download map tiles for offline use. GPS captures, coordinates and measurements are stored on the device and may still be entered without a network connection when the phone can obtain a location fix.

The tool shows preliminary spherical-earth area (m², ft², yd², km², hectares, acres and perches), perimeter, a two-point distance and true bearing, and a circle radius and approximate planar circle area. When both ruler points include GPS altitude it also shows an approximate slope. Altitude is WGS84 ellipsoidal height, not necessarily elevation above mean sea level. GPS horizontal/vertical accuracy and satellite/map alignment can be poor, particularly near obstructions. These measurements do not establish property boundaries, terrain survey, geotechnical suitability or final engineering design; use a qualified surveyor and the approved site documents. Self-intersecting, repeated-point and zero-area boundaries are flagged and not given an area.

**Export survey to Excel** saves a summary and point coordinates with source, operator, accuracy, altitude where available and UTC time. **Import Excel survey** restores an export into an empty site, so it cannot silently replace a survey that already contains points. The earlier scanner's Excel exports can be imported into the new app using **Module Serial Scanner → Import Excel backup**. Duplicates are skipped within each site, and serials remain text. Data on the website, each Android installation and different phones is separate; export and retain backups before uninstalling or clearing app data. Hosted test APKs use temporary signing keys, so a stable private signing key is required for reliable production updates.
